# 契约智控项目范围基线

> 版本：v1.1；日期：2026-09-17；状态：文档修订完成，待用户确认。  
> 本轮仅修订文档；Calicat 未同步、原型未验收、业务编码未开始。

## 1. 定位与协作方式

产品定位：面向项目型企业的 B2B SaaS 合同履约与回款风险管理平台。
项目用途：个人求职展示和完整学习 AI Coding。当前按个人主导开发规划；两人团队仅作为可行性参考，不假定存在第二位开发者，不承诺工期。

长期客户：中小工程公司、软件外包公司、设计公司、广告传媒公司、设备销售公司、咨询服务公司和律师事务所。
第一批验证客户：软件外包企业。第一版支持其共性合同履约流程，不承诺已适配所有行业特殊规则。

企业愿意付费的假设：减少漏跟进和证据查找时间、提前发现逾期、明确责任、形成可追溯履约记录。日常待办、验收和应收跟进构成持续使用理由。当前没有真实客户访谈或付费验证，不能宣称已验证商业收益。

## 3. 第一版范围

| 模块 | 第一版交付边界 |
|---|---|
| 企业与成员 | 实际多租户隔离、成员关系、预置角色、合同授权、禁用成员；至少两个模拟企业验证 |
| 平台身份 | 平台操作员可通过受控管理入口开通/停用租户，不默认读取企业合同或财务；完整运营页面延期 |
| 合同与文件 | 主档、文本型 PDF/DOCX 上传、私有文件、版本留存、新版本人工生效 |
| 解析确认 | 真实模型结构化提取、来源定位、人工修改确认、失败兜底；离线模拟模式单独标识 |
| 履约 | 固定日期/单一业务事件加自然日、节点草稿、发布、责任人、凭证审核、驳回重提、延期审批 |
| 财务 | 本企业作为收款方的应收计划、手工发票登记、多次部分回款、错误记录作废留痕 |
| 风险 | 固定规则、去重、通知、知悉确认、处置、关闭/忽略/再打开；检测贯穿全程 |
| AI 助手 | 当前授权合同原文 RAG、只读业务 Tools、风险/履约摘要、来源和时间标识 |
| 结项 | 完成检查、终止处理、归档快照、保留未结应收、审计查询 |
| 界面与测试 | 现有 P01—P08 局部补齐，增加最小成员授权页面 P09；多租户和异常端到端验收 |

补充边界：
- “付款节点”在本版统一指对方应向本企业支付的收款节点；供应商应付及实际转账不做。
- 人工业务链路必须能在模型不可用时继续运行。
- 只使用脱敏模拟数据，不在本版承诺真实敏感合同的商用上线能力。
- 自助注册和自动企业认证不做；企业及初始管理员由平台受控开通，成员由企业管理员添加已有账号或创建初始账号。身份、初始凭据和密码变更在后续技术设计中落实。

## 4. 延期清单与律所价值

延期：完整平台运营端、在线订阅支付、复杂套餐引擎、OCR、签章、银行流水/税务接口、自定义流程、复杂规则编辑器、批量审批、多币种、跨合同核销、复杂合并开票、AI 语义版本对比、自动续签、企业制度通用 RAG、WebSocket 增强、Spring Cloud 微服务。

律所独立价值是：多个客户的隔离合同空间、律师按客户/项目授权、人工签发意见及沟通交付历史。企业法务角色只服务当前获授权企业，不能据此宣传已支持律所版。
律所完整工作台和跨客户汇总延期；当前以企业租户和成员授权作为基础，不提前建设独立客户空间体系。未来客户空间归属、委托关系与意见签发流程需另行确认。

## 5. 商业模式假设

企业订阅包含一定成员数、活跃合同数与 AI 用量，超额增购；具体价格待客户验证。
不限制历史合同只读来强迫续费；历史保留与导出政策在商业试点前确认。
律所后续可按客户空间或项目配额计费。
第一版只定义业务指标与额度概念，不接支付、不建立复杂计费服务。

## 6. 技术边界与学习顺序

模块化单体：Spring Boot + MyBatis + MySQL；前端 Vue 3 + Element Plus；MinIO 保存私有附件。
Redis 优先会话、验证码、限流，缓存后置且带租户与权限范围；财务正确性依靠数据库事务和约束。
RabbitMQ 用于解析/索引工作和通知派发；定时扫描持久化节点产生提醒，需幂等、失败记录及重试。数据库提交后的事件可靠派发采用持久化待发送记录和补偿，具体实现留待技术设计。
LangChain4j 在人工业务闭环通过后接入。只做合同 RAG，不建设全行业知识平台。
测试伴随每个模块，不在项目末尾才开始。版本选型、部署方式、模型供应商及费用上限在编码前技术设计中确认。

## 8. 待用户确认的三项决策

以下为本次建议基线；确认前可改，不视作已实现：
- D1：企业版优先，律所完整工作台延期；收款侧优先，不做供应商应付。
- D2：第一版实现真实多租户及最小成员授权，使用两个模拟企业测试；不再仅保留 tenant_id 字段。
- D3：真实模型解析及合同 RAG 属于最终第一版验收；开发可先离线模拟，但必须标识且不能替代真实能力验收。

规则默认值已在需求中明确，可随确认调整：仅人民币、自然日、20MB/文件、人工指定不同审核人、全部提取项审阅完再发布、内部延期保留合同到期日。这些是产品默认值，不是法律结论。
